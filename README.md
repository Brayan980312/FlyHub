# FlyHub

**Sistema para gestión y compra de vuelos**

FlyHub es una aplicación web desarrollada con **React + TypeScript** y **Material UI**, diseñada para la gestión de vuelos y la compra de boletos. Incluye integración con APIs externas y un diseño moderno con iconos de Material UI.

---

## Tecnologías utilizadas

- **Frontend:** React 19.1.1 + TypeScript
- **Estilos y componentes UI:** Material UI
- **Iconos:** Material UI Icons
- **Gestión de dependencias:** npm
- **Node.js:** 20.19.5

---

## Requisitos previos

Antes de ejecutar el proyecto, asegúrate de tener instalado lo siguiente:

- **Node.js 20.19.5**
- **npm** (viene incluido con Node.js)
- Un editor de código recomendado: Visual Studio Code
- Conexión a internet para instalar dependencias y consumir las APIs

---

## Instalación

Sigue estos pasos para ejecutar FlyHub en tu máquina local:

1. Clona el repositorio:

```bash
   git clone https://github.com/Brayan980312/FlyHub
```

2. Ingresa a la carpeta de proyecto:

```bash
   cd flyhub
```

3. Instala las dependencias:

```bash
   npm install
```

4. Arranca el proyecto en modo desarrollo:

```bash
   npm run dev
```

5. Accede a la aplicación desde tu navegador:

```bash
   http://localhost:5173
```
